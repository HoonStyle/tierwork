# 작업 관제 UI

UI UX Pro Max 2.13.0의 `data dense dashboard --domain style` 결과(Data-Dense Dashboard)를 적용했다. 전체 디자인 시스템 검색은 IoT/랜딩 페이지로 분류되어 채택하지 않았다. 사용자 요청에 맞춰 어두운 작업 관제 화면, 모노스페이스 수치·시각, 구분된 단계와 활동 스트림을 사용한다. 추가 패키지나 원격 폰트는 없다.

- 함께 사용: 근거 검색 / 문서화 / 검증의 단계별 실제 상태와 세 도구의 활동 스트림. 공통 작업 ID가 없으므로 작업 진행률이나 연관성을 생성하지 않는다.
- Greplet: 인덱스 수치, 워크스페이스 표, 검색 활동, 서비스 상태.
- Legacy Spec: 문서 라이브러리와 원문 미리보기, 기존 인용 감사 기록.
- Tierwork: 에이전트 기록, 알려진 토큰 값의 합과 표본 수, 세션별 작업 수. 시작 기록은 프로세스 생존 상태가 아니다.
- 실제 새 이벤트만 일회성 강조한다. 감소된 모션 설정에서는 애니메이션을 끈다.
- 5초 갱신, 일시 정지, 페이지가 숨겨지면 폴링 중지. 해시 기반 화면 이동과 브라우저 뒤로 가기를 지원한다.
- 문서 요청 순서 역전을 차단한다. 같은 데이터는 재렌더링하지 않으며 파일 버튼 포커스와 펼친 연결 정보, 표 가로 스크롤을 유지한다.

검증: JavaScript 문법, 기존 최신 기록 판정 테스트, 실 API 연결, 모의 DOM에서 4개 모드와 연결 실패 데이터 렌더링. 브라우저 시각 검증은 수행하지 않았다.
