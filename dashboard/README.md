# Plugin Desk

Tierwork에 포함된 통합 대시보드입니다. 별도 플러그인 설치 없이 Tierwork 저장소에서 `node dashboard/server.mjs`로 실행합니다.

Greplet, Legacy Spec Agent, Tierwork의 로컬 조회 대시보드. Node.js 22 이상, 추가 패키지 없음.

실행: 이 폴더에서 `npm start`, 접속: http://127.0.0.1:8787

- 함께 사용: 세 단계의 상태와 최근 결과. 공통 작업 식별자가 없는 기록을 같은 작업으로 추정하지 않습니다.
- Greplet: 로컬 HTTP API에서 인덱스와 최근 검색을 조회합니다. Greplet 서비스는 별도로 실행되어 있어야 합니다.
- Legacy Spec: `generated-spec`의 결과 파일 목록, 안전한 텍스트 미리보기, 감사 기록을 조회합니다. 기존 결과가 현재 코드와 일치함을 보증하지 않습니다.
- Tierwork: JSONL 로그의 최신 `(session_id, agent_id)` 기록을 표시합니다. 실제 프로세스 상태가 아닙니다. 토큰 누락은 0으로 계산하지 않습니다.

`config.json`에서 Greplet 주소, 문서 폴더, Tierwork 로그 목록, 포트를 변경한 뒤 서버를 재시작하세요. 상대 경로는 이 폴더 기준입니다. Tierwork 기본 경로는 `~/.tierwork/reviews.jsonl`이며 `TIERWORK_LOG`를 사용한다면 해당 경로로 수정하세요.

서버는 127.0.0.1에만 바인딩하며 데이터 조회만 수행합니다. 5초 자동 갱신, 문서 미리보기 최대 2 MB. HTML도 실행하지 않고 원문으로 표시합니다. 파일 부재, API 오류, 손상된 로그는 별도 표시합니다. 원본 플러그인을 수정하거나 분석 작업을 시작하지 않습니다.

테스트: `npm test`. 이 프로젝트는 로컬 파일 접근이 필요하므로 웹 호스팅 배포용이 아닙니다.

## Event Runner

공룡이 계속 달리며 새로 감지한 검색·문서·에이전트 기록마다 한 번씩 점프합니다. 최초 조회 기록은 제외하고 여러 기록은 차례대로 처리합니다. 점프 미리보기도 횟수에 포함되며 초기화 버튼으로 숫자를 0으로 되돌릴 수 있습니다. 횟수는 현재 페이지에서만 유지됩니다. 동작 줄이기 설정에서는 애니메이션을 생략하고, 페이지가 숨겨지면 달리기를 멈춥니다.
